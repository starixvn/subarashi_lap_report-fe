# LAP.Report

LAP.Report includes front-end code


## Tech Stack

**Client:** 
- Node v20
- React v18
- Webpack v5

**Server:** 
- .NET 6.0


## Installation

Install Node v20

Install LAP.Report dependencies with npm

```
  cd ./src/Fanex.Athena.Report.WebHost/ClientApp
  npm ci
```
    
## Build

To build this LAP.Report run

```
  npm run build-dev
```
or
```
  npm run build-pro
```


## Others

To format code before commit, run

```
  npm run format
```
To build with watch any code change, run

```
  npm run build-watch
```
